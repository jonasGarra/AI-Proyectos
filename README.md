# Kikos AI

Personal AI gateway and assistant.

## Objetivo

Construir un asistente personal multiproveedor capaz de:

- seleccionar el modelo adecuado para cada tarea;
- gestionar costes y cuotas;
- realizar fallback entre proveedores;
- comprimir contexto;
- utilizar búsqueda web;
- trabajar con documentos;
- mantener memoria;
- utilizar herramientas mediante MCP;
- asistir en programación;
- ofrecer diferentes niveles de permisos.

## Arquitectura inicial

Cliente → Kikos AI Core → Smart Router → OmniRoute → proveedores cloud
